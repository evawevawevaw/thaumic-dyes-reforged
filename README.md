# Thaumic Dyes: Reforged

## О моде

**Thaumic Dyes: Reforged**
Автор порта: **evawevawevaw**. Авторы оригинала: **KryptonCaptain и Amerem**.

Порт [Thaumic Dyes 1.10.5-0 для Minecraft 1.7.10](https://www.curseforge.com/minecraft/mc-mods/thaumic-dyes)
на Thaumcraft 4: Reforged. Добавляет окрашиваемые варианты брони, руническую
экипировку и улучшения, древнюю маску и категорию исследований DYES.
Реализованы 57 предметов, 24 окрашиваемые части, 208 исходных деклараций
магических рецептов и 37 объявлений исследований, включая пять ссылок.
Цикл в исходной декларации может создавать несколько рецептов.

В этой папке находится самостоятельный Gradle-проект с готовыми исходниками
и ресурсами. Декомпиляция оригинала, генераторы, рабочие заметки и история
репозитория для его сборки не нужны и не включены.

## Зависимости

Состав сверяется с `build.gradle`, `gradle.properties`,
`src/main/resources/META-INF/neoforge.mods.toml` и импортами Java.
Мод непосредственно использует классы `thaumcraft.*`; Curios и TerraBlender
также обязательны по metadata и требованиям Thaumcraft. В jar порта зависимости
не встраиваются. Версии сборки ниже фиксированы; совместимость более новых
версий, разрешённых metadata, требует проверки.

| Обязательный мод | Версия для этой сборки | Где брать |
| --- | --- | --- |
| Thaumcraft 4: Reforged | 1.1.3 для MC 1.21.1; metadata требуют 1.1.3+ | [Релиз 1.21.1](https://github.com/notlikethiss/thaumcraft-4-reforged/releases/tag/1.21.1), файл `thaumcraft-4-reforged-1.1.3-1.21.1.jar` |
| Curios API, NeoForge | 9.5.1+1.21.1; metadata требуют 9.5.1+ | [CurseForge, файл 9.5.1](https://www.curseforge.com/minecraft/mc-mods/curios/files/6529130), основной jar, не `api` и не `sources` |
| TerraBlender, NeoForge | 1.21.1-4.1.0.1; metadata требуют 4.1.0.1+ | [CurseForge, файл 4.1.0.1](https://www.curseforge.com/minecraft/mc-mods/terrablender-neoforge/files/5673063) |

Опциональные просмотрщики рецептов подключаются на стороне Thaumcraft;
сам аддон не импортирует их API и не требует их для сборки.
В metadata Thaumcraft обе зависимости optional без ограничения версии.
В его предоставленной конфигурации указаны:

- [JEI](https://www.curseforge.com/minecraft/mc-mods/jei) — **19.57.0.451** для MC 1.21.1 / NeoForge.
- [REI](https://www.curseforge.com/minecraft/mc-mods/roughly-enough-items) — **16.0.799** для MC 1.21.1 / NeoForge.

Это версии из конфигурации зависимости, а не подтверждение игровой совместимости.
Для сборки порта они не нужны. При установке просмотрщика также соблюдайте
список зависимостей выбранного файла на его странице.

## Что изменено в порте

- Minecraft/Forge 1.7.10 заменены на Minecraft 1.21.1 / NeoForge: регистрации
  через DeferredRegister, современная модель брони и клиентские события.
- Цвет использует `minecraft:dyed_color`, улучшения — persistent/network
  Data Components и совместимые tags инфузии TC. Доступны все 16 красителей,
  смешивание оттенков и очистка водяным котлом. Оттенки современной палитры
  могут отличаться от 1.7.10; после очистки используется белый цвет.
- Метаданные старых ресурсов сопоставлены современным ID/компонентам,
  Ore Dictionary заменён общими тегами. Сохранены gates исследований и цены.
- Магические рецепты и исследования регистрируются через существующий API
  Thaumcraft Reforged. Его таблицы статические: это не рецепты, загружаемые
  datapack JSON. Аспекты восстанавливаются через registrar при reload.
- Исходные PNG сохранены, пути приведены к нижнему регистру; item sprites
  явно добавлены в атлас. Переводы en_us, ru_ru и zh_cn преобразованы в JSON.
  Десять моделей брони переведены на ModelPart, сохранены геометрия и анимации;
  первозданная броня использует отдельный translucent render layer.
- По запросу автора порта обычная и усиленная руническая броня видимы при
  ношении, хотя в оригинале они прозрачны. Runic I использует модель железной
  крепостной брони и таумиевые текстуры ботинок; Runic II — модель претора и
  пустотные текстуры ботинок. Характеристики от этого не изменены. Иконки GUI
  остались оригинальными. Очки и ботинки путешественника имеют свои текстуры.
- Рунические эффекты учитывают все доступные слоты улучшений; исправлены
  недостижимые ветки оригинала. Cooldown задан в игровых тиках; состояние
  улучшений сбрасывается при выходе и возрождении.
- Emergency Shielding реализован собственным резервом защиты и HUD, поскольку
  публичного setter заряда в TC нет. Резерв даёт 8 единиц на улучшение с
  cooldown 2400 тиков; сумма резерва и native заряда ограничена максимумом.
  Штатная перезарядка не видит резерв, поэтому расход vis и взаимодействие
  перезарядки отличаются от оригинала. Частные поля TC не изменяются.
- ISpecialArmor заменён современной защитой/атрибутами и NeoForge damage
  events; формулы не полностью тождественны 1.7.10. Hardened II даёт +1 armor.
- Древняя маска выбирает цели на сервере с LOS/PvP-проверками, собственной
  синхронизацией и lightning. Сохранены три достижимых debuff оригинала;
  недостижимый четвёртый вариант и нерабочая UUID-ветка отсутствующей текстуры
  не воспроизводятся.
- Сохранены саморемонт надетой void armor, движение traveller boots,
  revealing/goggles, vis discount, warp, runic shield и fortress integration.
  Собственных блоков, сущностей, worldgen или контейнерного GUI в оригинале нет.
  Миграция миров 1.7.10 не реализована.

**Граница проверки:** при подготовке папки успешно выполнены офлайн-сборка
и статическая сверка. Игра не запускалась. Загрузка dedicated server,
посадка/прозрачность/анимации брони, весь survival-прогресс, стоимость магии,
совместимость JEI/REI, синхронизация и PvP **требуют проверки в игре**.
Код Thaumcraft Reforged в этом проекте не изменяется.

## Сборка

Нужен JDK 21. Gradle устанавливать отдельно не нужно — используется wrapper.
Curios и TerraBlender разрешаются Gradle по версиям из `gradle.properties`.
Thaumcraft подключается готовым внешним jar; его исходники не требуются.

Подготовьте `thaumcraft-4-reforged-1.1.3-1.21.1.jar` одним из способов:

1. Создайте `libs/` в этой папке и положите jar туда.
2. Укажите путь в переменной окружения `THAUMCRAFT_JAR`.
3. Передайте путь свойством Gradle `-Pthaumcraft_jar=/путь/к/файлу.jar`.

Свойство Gradle имеет приоритет над переменной окружения, затем используется
`libs/thaumcraft-4-reforged-1.1.3-1.21.1.jar`. Внешний jar в комплект не включён.

Linux/macOS, из корня проекта:

```sh
export THAUMCRAFT_JAR="/путь/к/thaumcraft-4-reforged-1.1.3-1.21.1.jar"
./gradlew build --offline
```

Windows PowerShell:

```powershell
$env:THAUMCRAFT_JAR = "C:/mods/thaumcraft-4-reforged-1.1.3-1.21.1.jar"
.\gradlew.bat build --offline
```

Если jar уже лежит в `libs/`, переменная не нужна. Для офлайн-сборки wrapper,
NeoForge, mappings и остальные артефакты должны находиться в локальном Gradle
cache. Если артефакта нет, сборка остановится; эта папка не содержит кэш.
В ходе подготовки зависимости из сети не скачиваются.

Результат после сборки:
`build/libs/thaumic-dyes-reforged-1.10.5-reforged.6-1.21.1.jar`.
`build/` и `.gradle/` создаёт сама сборка; они не входят в чистый комплект исходников.
Проверка не требует runClient, runServer, runData или запуска Minecraft.

## Установка

1. Подготовьте Minecraft 1.21.1 с NeoForge 21.1.256 и Java 21.
2. Установите перечисленные обязательные Thaumcraft Reforged, Curios и
   TerraBlender для правильных Minecraft/NeoForge.
3. Положите собранный jar порта в `mods/` игрового профиля и, для сервера,
   в `mods/` сервера вместе с его обязательными зависимостями.
4. Заменяйте предыдущую версию jar порта, затем перезапускайте игру.

Саму папку исходников, wrapper и JDK в `mods/` помещать не нужно.
