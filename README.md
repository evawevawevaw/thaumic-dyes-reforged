# Thaumic Dyes: Reforged

## О моде

**Thaumic Dyes: Reforged**
Автор порта: **evawevawevaw**. Авторы оригинала: **KryptonCaptain и Amerem**.

Порт [Thaumic Dyes 1.10.5-0 для Minecraft 1.7.10](https://www.curseforge.com/minecraft/mc-mods/thaumic-dyes)
на Thaumcraft 4: Reforged. Добавляет окрашиваемые варианты брони, руническую
экипировку и улучшения, древнюю маску и категорию исследований DYES.
Реализованы 57 предметов, 24 окрашиваемые части, 208 исходных деклараций
магических рецептов и 37 объявлений исследований, включая пять ссылок.
Цикл в исходной декларации может создавать несколько рецептов.

В этой папке находится самостоятельный Gradle-проект с готовыми исходниками
и ресурсами. Декомпиляция оригинала, генераторы, рабочие заметки и история
репозитория для его сборки не нужны и не включены.

## Зависимости

Состав сверяется с `build.gradle`, `gradle.properties`,
`src/main/resources/META-INF/neoforge.mods.toml` и импортами Java.
Мод непосредственно использует классы `thaumcraft.*`; Curios и TerraBlender
также обязательны по metadata и требованиям Thaumcraft. В jar порта зависимости
не встраиваются. Версии сборки ниже фиксированы; совместимость более новых
версий, разрешённых metadata, требует проверки.

| Обязательный мод | Версия для этой сборки | Где брать |
| --- | --- | --- |
| Thaumcraft 4: Reforged | 1.1.3 для MC 1.21.1; metadata требуют 1.1.3+ | [Релиз 1.21.1](https://github.com/notlikethiss/thaumcraft-4-reforged/releases/tag/1.21.1), файл `thaumcraft-4-reforged-1.1.3-1.21.1.jar` |
| Curios API, NeoForge | 9.5.1+1.21.1; metadata требуют 9.5.1+ | [CurseForge, файл 9.5.1](https://www.curseforge.com/minecraft/mc-mods/curios/files/6529130), основной jar, не `api` и не `sources` |
| TerraBlender, NeoForge | 1.21.1-4.1.0.1; metadata требуют 4.1.0.1+ | [CurseForge, файл 4.1.0.1](https://www.curseforge.com/minecraft/mc-mods/terrablender-neoforge/files/5673063) |

Опциональные просмотрщики рецептов подключаются на стороне Thaumcraft;
сам аддон не импортирует их API и не требует их для сборки.
В metadata Thaumcraft обе зависимости optional без ограничения версии.
В его предоставленной конфигурации указаны:

- [JEI](https://www.curseforge.com/minecraft/mc-mods/jei) — **19.57.0.451** для MC 1.21.1 / NeoForge.
- [REI](https://www.curseforge.com/minecraft/mc-mods/roughly-enough-items) — **16.0.799** для MC 1.21.1 / NeoForge.

Это версии из конфигурации зависимости, а не подтверждение игровой совместимости.
Для сборки порта они не нужны. При установке просмотрщика также соблюдайте
список зависимостей выбранного файла на его странице.

## Что изменено в порте

**Платформа.** Мод перенесён с Minecraft 1.7.10 / Forge на Minecraft 1.21.1 / NeoForge: новые регистрации, современная модель брони и клиентские события.

**Окраска.**
- Доступны все 16 красителей, цвета можно смешивать.
- Краску смывают в котле с водой, после очистки цвет становится белым.
- Оттенки могут слегка отличаться от версии 1.7.10.

**Рецепты и исследования.** Они добавляются через API Thaumcraft Reforged. Он не поддерживает datapack JSON, поэтому рецепты и исследования заданы в коде. Условия открытия исследований и цены сохранены.

**Ресурсы.** Исходные текстуры сохранены (имена файлов приведены к нижнему регистру). Переводы на en_us, ru_ru и zh_cn переведены в JSON. Модели брони переписаны под современный движок, геометрия и анимации сохранены. Первозданная броня полупрозрачна, как в оригинале.

**Отличия от оригинала**
- Обычная и усиленная руническая броня теперь видна на игроке (в оригинале она прозрачна). Характеристики не менялись.
- Аварийный щит (Emergency Shielding) сделан как отдельный резерв защиты со своим индикатором на экране. Заряд Thaumcraft напрямую изменить нельзя, поэтому расход vis и перезарядка работают не так, как в оригинале. Резерв даёт 8 единиц защиты за улучшение, перезарядка 2400 тиков (2 минуты).
- Формулы защиты не полностью совпадают с 1.7.10. Hardened II даёт +1 к броне.
- Древняя маска стала серверной: она проверяет видимость цели и правила PvP. Сохранены три рабочих эффекта оригинала, недостижимый четвёртый и нерабочая ветка с отсутствующей текстурой убраны.
- Исправлены недостижимые ветки рунических эффектов. Они теперь учитывают все слоты улучшений, а их состояние сбрасывается при выходе из игры и возрождении.

**Сохранено из оригинала.** Саморемонт надетой пустотной брони, движение ботинок путешественника, показ аур и очки, скидка на vis, варп, рунический щит, интеграция с крепостной бронёй.
